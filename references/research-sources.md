## Source hierarchy
1. Official project documentation and specifications.
2. Standards bodies and primary security guidance.
3. Maintainer-authored release notes and migration guides.
4. Reputable technical publications for context.

Do not treat a search snippet, AI-generated answer, or unmaintained tutorial as proof of current API behavior.
